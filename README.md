# 🐱⚡ CATOMON

**Превращай фото своих котов в коллекционные покемон-карточки!**

Сфотографируй (или загрузи) кота — AI проанализирует его и создаст уникальную карточку с типом, статами, способностями, а также в стиле классических голографических покемон-карт.

## 🎮 Что умеет

- 📸 Загрузка фото или съёмка прямо с камеры телефона
- 🧠 AI-анализ фото (GPT-4o-mini) и генерация карточки с учётом окраса и выражения морды
- ✨ Настоящая **голографическая 3D-карточка** с эффектом фольги, реагирующая на движение мыши
- 🎴 12 типов стихий (Огонь, Вода, Трава, Электро, Психо, Тёмный, Фея, Боевой, Призрак, Лёд, Камень, Нормальный)
- ⭐ 5 уровней редкости: обычная → легендарная
- 📊 5 характеристик (HP, АТК, ЗАЩ, СКР, СПЦ) + 2 уникальные атаки
- 💾 **Серверная часть** на Vercel Serverless Functions (папка `/api`)
- 📖 Личный **Покедекс** — все созданные карточки сохраняются в браузере
- 💾 Скачивание любой карточки в формате PNG (высокое разрешение для печати)
- 🌙 Полностью адаптивный дизайн, тёмная тема, пиксельный шрифт Press Start 2P

## 🚀 Деплой на Vercel

Проект уже полностью настроен под Vercel. Просто:

1. Залейте в репозиторий GitHub.
2. На Vercel → Add New Project → импортируйте репозиторий.
3. **Framework preset** определится автоматически как Vite.
4. Нажмите Deploy.

Без дополнительных настроек работает локальный генератор карточек (он тоже создаёт очень забавные и разнообразные варианты).

## 🆓 Работает БЕЗ API-ключа и без денег

По умолчанию включён режим **«Умный анализ фото»** — он не требует ни ключа, ни интернета, ни оплаты.

Как это работает: фото загружается в `<canvas>`, уменьшается до 80×80 и разбирается по пикселям прямо в браузере. Считаются:

| Признак | Что даёт |
|---------|----------|
| Доминирующий оттенок (HSL-гистограмма, центр кадра) | **Стихию**: рыжий → Огонь, серо-голубой → Вода, тёмный → Тьма/Призрак, белый → Лёд/Фея, жёлтый → Электро |
| Доля тёмных пикселей | **HP** и **Защиту** (чем «увесистее» кот, тем больше) |
| Контраст (СКО яркости) | **Атаку** (полосатые и резкие коты агрессивнее) |
| Детализация / краевой шум | **Пушистость** → Скорость и Защита |
| Насыщенность | **Спец-атаку** и шанс редкости |
| FNV-хэш всех пикселей | Семя генератора |

Благодаря хэшу результат **детерминированный** — один и тот же кот всегда получает одну и ту же карточку, как настоящая запись в покедексе. После сканирования показывается «Отчёт сканера» с извлечённой палитрой и метриками.

Тексты (имена, атаки, описания, титулы) берутся из большой встроенной базы на трёх языках — сотни тысяч комбинаций.

### 🧠 Подключить нейросеть (опционально, тоже бесплатно)

Если хотите, чтобы имя, описание и атаки придумывала настоящая нейросеть, глядя на фото — подключите **Google Gemini**. У него есть щедрый бесплатный тариф, платить не нужно.

> ⚠️ **НИКОГДА не пишите ключ в коде и не публикуйте его.** Ключ задаётся только через переменные окружения. Если ключ где-то засветился — сразу удалите его и создайте новый.

1. Получите бесплатный ключ: [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → **Create API key**. Ключ выглядит как `AIzaSy...`
2. Откройте ваш проект на [vercel.com](https://vercel.com) → вкладка **Settings**
3. Слева в меню выберите **Environment Variables**
4. Заполните:
   - **Key:** `GEMINI_API_KEY`
   - **Value:** ваш ключ
   - **Environments:** отметьте все три (Production, Preview, Development)
5. Нажмите **Save**
6. Вкладка **Deployments** → у последнего деплоя «···» → **Redeploy**
7. На сайте выберите режим «🧠 Нейросеть (Gemini)»

Используется модель **gemini-2.0-flash** — быстрая, мультимодальная, с бесплатным лимитом.

#### Альтернатива: OpenAI (платно)

Функция также поддерживает `OPENAI_API_KEY` (модель `gpt-4o-mini`). Если заданы оба ключа, приоритет у Gemini.

#### Локально (для разработки)

Создайте файл `.env.local` в корне проекта (он не попадёт в Git):

```
GEMINI_API_KEY=ваш-ключ
```

## 🌍 Языки

Приложение доступно на трёх языках, переключатель — в шапке справа:

- 🇷🇺 Русский
- 🇺🇦 Українська
- 🇬🇧 English

Переводится **всё**: интерфейс, названия стихий, редкость, а также сам генерируемый контент — имена котов, названия атак, способности и юмористические описания написаны отдельно для каждого языка. AI (при включённом ключе) тоже получает инструкцию отвечать на выбранном языке.

Язык определяется автоматически по языку браузера и запоминается в `localStorage`.

## 📁 Структура

- `src/App.tsx` — главный компонент приложения
- `src/components/HoloCard.tsx` — карточка с 3D-голографическим эффектом
- `src/components/UploadZone.tsx` — зона загрузки/съёмки
- `src/components/ScannerAnimation.tsx` — анимация анализа
- `src/lib/generator.ts` — клиентский генератор (фоллбек если AI отключён)
- `src/lib/types.ts` — типы и метаданные типов стихий
- `api/generate.ts` — серверлесс-функция Vercel, прокси к OpenAI (работает и без ключа)
- `vercel.json` — конфигурация хостинга

## 💾 Как хранятся данные

- **Созданные карточки** — в `localStorage` браузера пользователя (в Покедексе).
- **AI-логика** — на серверлесс-функции Vercel (не требует отдельного сервера).

При желании можно добавить общую базу данных — Vercel Postgres/KV подключается в пару кликов.

## 💡 Заметки

- Фото котов **никуда не отправляются**, если вы не включили AI.
- При включении AI фото отправляется в OpenAI только на время обработки (не сохраняется).
- Благодаря `vite-plugin-singlefile` фронтенд собирается в один HTML-файл.
